# Documentation Checklist

- [ ] Only what actually changed was updated — no unrelated rewrite.
- [ ] New documents follow `docs/<category>/<NNN>-<kebab-case-name>.md`, numbered sequentially.
- [ ] No `.docx` file was modified — only the corresponding `.md`.
- [ ] All relative links in the changed document(s) resolve to real files.
- [ ] Any content conflict with another document was flagged, not silently resolved.
- [ ] No reference to `docs/decisions/`, `docs/api/`, or `docs/engineering/technical-debt.md` was treated as if the path exists, unless it was created as part of this change with explicit approval.
