# Release Checklist

Per `docs/development/015-development-workflow.md`:

- [ ] All tests pass (that actually exist to run).
- [ ] Documentation updated to match released behavior.
- [ ] Security review completed for security-sensitive changes in this release.
- [ ] Deployment validated.
- [ ] Release notes document features, fixes, and breaking changes.
- [ ] No numeric quality threshold was invented — only documented, qualitative gates were applied.
