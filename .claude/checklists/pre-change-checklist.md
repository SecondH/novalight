# Pre-Change Checklist

Before starting any non-trivial change (per `CLAUDE.md` §4):

- [ ] Read the relevant documents per the `CLAUDE.md` §3 routing table.
- [ ] Ran `repository-analysis` to confirm current state of the affected area.
- [ ] Identified dependencies and blast radius.
- [ ] Assumptions stated explicitly, not silently assumed.
- [ ] Change classified: Minor / Medium / Major (per Claude Code Operating Model §8).
- [ ] For Medium/Major: a plan exists (`feature-planning`).
- [ ] Required approvals identified per the `CLAUDE.md` §15 risk matrix.
